# Три политические карточки

Все выводы предварительные; независимой человеческой валидации нет.

1. [Объявление отставки → уход](politics_resignation_departure.json): условная импликация по сохранённым правилам при согласованных источниках сообщений. Обе стороны учитывают объявление, даже если оно вступает в силу позднее.
2. [Импичмент / уход](politics_impeachment_departure.json): четыре сценария показывают отсутствие строгой логической связи в объявленной области. Это не утверждение статистической независимости.
3. [Уход на Polymarket / Kalshi](politics_crossvenue_departure.json): бинарная эквивалентность не установлена; официальный Kalshi API содержит небинарную ветвь выплаты. Обычный бинарный подслучай отдельно не разобран, поэтому его состояния отмечены unknown, а не impossible.

В каждой карточке есть ID, URL, происхождение текста, SHA-256 файла, область вывода и основания. Polymarket `rules_raw` получены из публичного API [ClearMarket](https://clearmarket.fyi), которому принадлежит копия и её дополнительная классификация; editorial-поля в доказательстве не использованы. Официальная текущая Gamma-редакция не подтверждена. Kalshi primary/secondary получены напрямую.

Сборка и проверка схемы: `python3 redesign/build_political_cards.py` из корня проекта. Исходные тексты — в `political_inputs.json`. Независимый AI-review проверил смысл трёх карточек; после него уточнено, что наличие небинарной ветви не делает обычные бинарные сценарии принципиально непознаваемыми.
