# Пилот v2 — карта файлов

Основное объяснение: [PILOT_V2_RU.md](../PILOT_V2_RU.md). Вспомогательный [выполненный notebook](../notebooks/pilot_v2.ipynb) содержит sanity check; основные выводы — в [README](../README.md).

- `retrieval/` — зафиксированный план запуска, входы, эмбеддинги, ранги, метрики и независимая проверка вычислений. `environment.json` фиксирует версии локального окружения после запуска.
- `datasets/` — происхождение внешних 493 пар, проверка ID и меток, pinned commit и скрипт аудита.
- `cards/` — три предварительные политические карточки с областью вывода, источниками и сценариями.
- `discovery/official_probe/PAIR_CARDS.md` — ещё шесть качественных разборов из macro, gaming, sports; JSON и исходные ответы рядом.
- `protocol.md`, `schema.json` — проект протокола дальнейшей разметки. Намеченные 12–18 карточек не набраны: фактически подготовлено 9. Подробную унифицированную схему сейчас реализуют три политические карточки; остальные шесть остаются кандидатами для аннотации. Два пороговых контроля в новый набор не добавлялись.

Для просмотра результатов модели не нужны. Полный пересчёт из корня проекта:

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r pilot/requirements.txt -r extension/nlp/requirements.txt
python extension/nlp/download_models.py
python redesign/run_retrieval.py
```

Веса занимают около 0,85 GB; готовые веса из прежнего запуска повторно используются через `tmp/hf_cache`. Notebook-генератор дополнительно использует `nbformat`, `nbclient`, `ipykernel` и `matplotlib`; открытие готового `.ipynb` не требует повторного inference. В текущей среде запуск выполнен на macOS/CPU; отдельная Linux-проверка не проводилась.

Авторский audit-набор — внешний эталон известных соответствий внутри отобранного корпуса, а не независимый human gold отношений выплат. Качественные карточки не используются для расчёта accuracy. Старый CPI-пилот сохранён в соседних `pilot/` и `extension/` как история работы.
