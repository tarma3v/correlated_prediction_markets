# Связи между контрактами по условиям resolution

Исследовательский прототип для Polymarket и Kalshi: выявление эквивалентности, вложения и несовместимости **условий выплат** с явными предпосылками и проверяемыми основаниями. Тематическая близость и статистическая корреляция - отдельные задачи.

## Материалы ВКР к встрече 18 ноября

[Рукопись](docs/thesis/THESIS_RU.md) · [PDF](docs/thesis/thesis.pdf) · [Слайды](docs/thesis/slides/slides.pdf) · [Реестр гипотез](docs/thesis/HYPOTHESES_RU.md) · [Как воспроизвести расчёты](docs/thesis/README.md)

В условной скалярной модели выплат у 500 из 555 высказанных NLI-отношений найден числовой контрпример. На реальных расчётах core CPI портфели строгих порогов воспроизвели 21 выплату по трём одинаковым месячным значениям. В четырёх дневных панелях межплощадочная модель уступила прогнозу по последней цене. Рукопись описывает область каждого вывода и оставшиеся условия независимой проверки.

| [Небинарная ветвь KXTRUMPOUT27](research/validated_findings.md) | В случае смерти предусмотрен расчёт по последней цене либо определение выплат комитетом | Таблица четырёх бинарных исходов применима только к явно указанной области |
| [Аналитический нуль метрики референса v2](research/metric_null.md) | По опубликованным агрегатам константа `+` на выбранных AAI парах даёт 65,93% против фактических 62,85% | Агрегатный перерасчёт не заменяет воспроизведение по исходным рёбрам |

NLI-результат: **325/839 = 38,7%**, 19 групп шаблонов; сохранены вероятности, текстовые пороги и свидетели. [Код проверки](research/verify_findings.py) пересчитывает mapping и неравенства независимо от первоначального отчёта.

## Типизированные связи и протокол

[32 спорные пары](relations/README.md), ранее отмеченные внешним автором как `different` или `unsure`, разобраны по типам отношений, источникам и недостающим предпосылкам. Это предварительная разметка, не независимый gold. Корреляция по ценам не измерялась.

[Протокол](protocol/llm_prompt.txt) оценивает состояния `00/01/10/11`: запрет `10` означает A ⇒ B, запрет `11` - несовместимость. Для допустимости нужен свидетель; отсутствие доказательства означает `unknown`. Полноценное сравнение моделей по этому протоколу ещё не выполнено.
