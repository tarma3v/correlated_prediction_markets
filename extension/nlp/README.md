# Выполненные локальные MiniLM и DeBERTa: диагностика

Это продолжение исходного lexical pilot. Модели **фактически запущены локально на CPU**, без обучения, платного API и отправки текстов удалённому inference-сервису. Публичные веса загружены с Hugging Face, версии закреплены commit SHA. Исходные 286 контрактов не изменены.

## Данные и воспроизведение

`run_manifest.json` хранит модель, revision, версии библиотек, seed, hashes и даты. `nli_inputs.json` содержит точные входы до inference, `nli_predictions.json` — ответы. `dense_embeddings.npz` позволяет воспроизвести ранжирование без повторного inference. Веса моделей не включены в архив проекта; загрузка занимает около 0,85 GB.

Основной локальный запуск использовал Python 3.11.4, torch 2.0.1, transformers 4.44.2. Отдельная Linux-проверка не выполнялась. Числа softmax — scores модели, не калиброванная вероятность правильности договорного вывода.

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r extension/nlp/requirements.txt
python -m pip install -r pilot/requirements.txt
python extension/nlp/download_models.py
python extension/nlp/run_models.py
python extension/nlp/synthetic_v2.py
python extension/nlp/eligible_retrieval.py
python extension/nlp/score_candidate_pool.py
python extension/nlp/conditional_consistency.py
```

Команды выполнять из корня проекта. Для чтения готовых результатов установка моделей не нужна. Поиск выполняется на сохранённом снимке, не на новых рынках. Новые времена в manifests будут отличаться. Точное побитовое совпадение float на другом оборудовании не обещается.

## Dense retrieval

Модель [all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2), mean pooling с attention mask, L2-нормализация, CPU float32. Три входа: title, primary+secondary, title+primary+secondary. Обработано 286×3=858 текстовых входов; лимит 256 токенов, усечения нет. Само ранжирование — полная матрица O(n²), не ANN.

- Пропущенная lexical top-5 октябрьская CPI-пара >0.9 / >0.8 попала в dense top-5 во всех трёх views. Это конкретное восстановление post-hoc контроля, не доказательство роста population recall.
- Пара разных месяцев также остаётся кандидатом в dense title+rules top-5. Близость в embedding space не классифицирует отношение.
- Межсерийная условная пара month→any-month не попала в обычный dense top-5: минимальный rank title+rules =6. После чтения terms её нельзя считать безусловным positive gold.

Результаты: `dense_summary.json`, `dense_case_ranks.json`.

## Порядок фильтрации cross-event

Если исключать пары из одного event **после** top-k, ближайшие внутри-event контракты уже занимают места в выдаче. В диагностике сравнили фильтрацию до/после ranking на тех же embeddings и lexical scores; результат в `eligible_retrieval.json`.

| k=5, union трёх views | Фильтр после top-k | Фильтр до top-k |
|---|---:|---:|
| Lexical cross-event пары | 349 | 1 455 |
| Dense cross-event пары | 19 | 1 849 |

Это увеличение **бюджета кандидатов**, не доказательство улучшения качества. Сравнивать downstream точность нужно при одинаковом бюджете и на gold, которого пока нет. Для основного cross-event трека полезно явно задавать eligibility до поиска, а same-event пороги оставлять отдельным контролем. Условный month→any-month кандидат в dense title+rules становится первым допустимым соседом в одном направлении; это свойство одного выбранного кейса.

## NLI на шести реальных парах

Модель [DeBERTa-v3-base-mnli-fever-anli](https://huggingface.co/MoritzLaurer/DeBERTa-v3-base-mnli-fever-anli); label mapping читается из config и проверяется. Для 6 ранее выбранных пар — 3 views × 2 направления =36 входов. Лимит 512; усечения нет.

| Кейс | View | A→B | B→A | Исследовательская интерпретация |
|---|---|---|---|---|
| ≥7% / ≥6.5%, одинаковый title | title | entailment 0.990 | entailment 0.990 | Title не содержит порога; симметрия ответов не доказывает эквивалентность контрактов |
| Те же пороги | title_rules | contradiction 0.906 | contradiction 0.989 | При общем ряде более высокий порог не исключает низкий; модельный contradiction нельзя считать hard exclusion |
| Октябрь >0.9% / >0.8% | title_rules | contradiction 0.948 | contradiction 0.916 | Расходится с алгеброй стандартного общего значения; полные контрактные исключения обсуждаются отдельно |
| Core YoY декабрь / ноябрь >2.6% | title_rules | contradiction 0.969 | contradiction 0.900 | Разные месяцы не запрещают оба Yes; фактическая совместимость всех условий требует собственного анализа |

Views имеют разные смысловые ограничения: `title` содержит вопросы; `title_rules` смешивает вопросы и условные описания; `event_clause` удаляет оболочку If/then и **не содержит secondary**. Это диагностика зависимости от представления, не финальный payoff-classifier. Во всех сравнениях указывать view, не выбирать лучший ответ задним числом.

## Исправленный синтетический контроль v2

Версия 1 сохраняется полностью. Независимый аудит нашёл повторные направленные тексты и неоднозначность между непрерывной игрушечной величиной и реальной десятичной точностью CPI. Поэтому версия 2 **до нового inference** удаляет точные дубликаты и явно задаёт вымышленные непрерывные показатели. Изменение сделано после просмотра v1 и не является независимым закрытым тестом.

Для двух скалярных неравенств representative points покрывают обе границы, интервалы между ними и хвосты; это полная разбивка непрерывной оси для таких предикатов. Разные контексты задают разные неограниченные переменные; это отсутствие логических ограничений, не утверждение статистической независимости. Доказуемые label правила: A⇒B — entailment; иначе невозможность совместного Yes — contradiction; иначе neutral. Это proposition-NLI, не полный контракт.

**V2: 32 правильных ответа из 63 уникальных упорядоченных текстовых пар.** Из 33 neutral правильны 5, в 23 случаях модель выбрала contradiction и в 5 — entailment. Все 18 contradiction распознаны; entailment — 9 из 12. Always-neutral baseline дал бы 33/63 на именно таком составе. Эти числа характеризуют только выбранные шаблоны; пары зависимы, распределение искусственное, CI и общий вывод о точности модели на рынках не делаются.

Для прозрачности: v1 дала 40/72 направленных оценок; после удаления повторов тех же v1-текстов 34/63. V2 отличается и формулировкой контекста, поэтому32/63 нельзя приписывать одному удалению дубликатов. Все входы и outputs сохранены: `synthetic_v2_inputs.json`, `synthetic_v2_predictions.json`, `synthetic_v2_manifest.json`.

## NLI на полном исходном candidate pool

`score_candidate_pool.py` завершил обработку всех 1 188 пар lexical top-5 в обе стороны, один view title+primary+secondary, всего 2 376 inference-входов, без усечения. CPU wall time около 383 секунд в этом запуске, без времени скачивания весов; это не контролируемый speed benchmark. Выход и завершение проверяются по `corpus_run_manifest.json`, индивидуальные scores — `corpus_nli_predictions.json`. Правила вывода зафиксированы перед inference: threshold 0.80, margin 0.10. Contradiction-кандидат интерпретируется как предполагаемое exclusion, не complement; каждый output имеет `verified:false`.

Распределение: exclusion 443, equivalence 148, A→B 58, B→A 54, abstain 485. Для 349 cross-event пар: exclusion 118, B→A 30, abstain 201. Направление A/B определяется сохранённым порядком endpoint IDs, поэтому само преобладание B→A не является законом рынка.

Распределение меток в manifest — результат работы модели, **не оценка правильности**, не gold и не число обнаруженных строгих связей. Это также не точное воспроизведение референса: другой snapshot, retrieval, входы и оценка. Веса/threshold не настраивались на результаты нашего корпуса.

## Сопоставление с условной скалярной моделью

`conditional_consistency.py` соединяет outputs с одинаковыми event-шаблонами из retrieval experiment. Совпали 839 пар, 19 групп. На 325 из них NLI предложила exclusion. Для каждой сохранён свидетель x=max(threshold_A,threshold_B)+1, при котором обе нижние пороговые пропозиции истинны. Это противоречие в **заданной неограниченной общей скалярной модели**. Оно не является human-gold error rate и не сертифицирует полный договор. Наличие этого фильтра не доказывает улучшение на межсобытийном тесте; это отдельный исполняемый structural diagnostic.
