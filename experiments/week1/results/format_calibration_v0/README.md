# Начальная калибровка интерфейса, v0

Этот запуск остановлен после 30 завершённых вызовов. В 19 ответах схема JSON
не совпала с ожидаемой: свидетели часто записывались как строки вместо объектов
`{"x_a": "...", "x_b": "..."}`. В примере исходного промпта были показаны
только null-свидетели, что недостаточно явно задавало форму ненулевого ответа.

Сохранены все завершённые ответы, исходные prompts, config, runner и manifest.
Это неполный инженерный прогон. Его нельзя сравнивать по accuracy с финальным
запуском, дополнять выборочно только удачными ответами или считать holdout.

В v1 полный JSON schema добавлен в инструкции, а пример объекта свидетеля
уточнён. Затем заново выполнены все 24 пары и четыре LLM-ветки. Смысловые
задачи, модель, seed и token cap не менялись. Новые выходы являются результатом
другого интерфейса, поэтому численное before/after улучшение семантики здесь
не утверждается.
