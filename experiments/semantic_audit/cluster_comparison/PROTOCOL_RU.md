# Объединение поисковых списков и жёсткие кластеры

17 ноября 2026. В исходном отчёте предложено сравнить полноту объединённого lexical/dense поиска с поиском внутри жёстких тематических кластеров при одинаковом бюджете. Результаты обычного поиска E5 и TF–IDF на авторских ссылках известны. Сравнение с разбиением на кластеры задаётся до расчёта.

Основной контраст — поиск Polymarket → Kalshi среди 493 кандидатов. Знаменатель — 461 известная положительная ссылка внешнего автора. Модель E5-small-v2, вход событие плюс исход. Альтернировать результаты E5 и словесного TF–IDF, пропуская повторы. Кластерный вариант применяет тот же порядок, допуская только кандидатов из кластера запроса. Получить жёсткие кластеры сферическим k-means на объединённых эмбеддингах без авторских меток. Основная конфигурация — 16 кластеров, seed 17, максимум 20 кандидатов на запрос. Дополнительно 8 и 32 кластера, seeds 29 и 53, k=5, обратное направление и отдельные dense/lexical каналы. В каждом направлении свободный поиск выдаёт столько кандидатов, сколько смог выдать кластерный по данному запросу. Сохранить точное число проверок, попаданий и пропуски из-за границ. Разные запросы в одном направлении соответствуют разным исходным контрактам.

Проверка на полностью перечисленном условном блоке — 7 запросов Polymarket × 55 кандидатов Kalshi, 77 положительных связей при общем ноябрьском релизе в обычной модели. Для этого набора нет закреплённых эмбеддингов E5. Два канала — TF–IDF по заголовку и по заголовку с исходом и текстом правил. Разбить по вектору со всеми текстовыми полями. Основное число кластеров 3, чувствительность 2 и 5, те же seeds и k. Если методов нельзя сравнить из-за нулевого общего бюджета, показать это отдельно вместе с результатом свободного поиска при полном допустимом бюджете.

Ожидается положительная разность полноты в пользу свободного объединения при одинаковом числе проверок. Это проверка одного воспроизводимого жёсткого алгоритма. Сферический k-means не воспроизводит UMAP/HDBSCAN и исходный корпус статьи. На авторском наборе полнота касается только известных ссылок. Единственный CPI-релиз ограничивает выводы о других темах. Не выбирать число кластеров по результатам.
