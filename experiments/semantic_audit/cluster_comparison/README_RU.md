# Объединение поисковых списков и жёсткая кластеризация

В разделе 6 исходного отчёта предложено проверить, снижает ли жёсткое тематическое разбиение полноту поиска по сравнению с объединением lexical/dense кандидатов. Здесь проверяется практически важное условие — одинаковое фактическое число сравнений по каждому запросу, в том числе при пустом кластере. Для каждого направления рынок-запрос уникален, поэтому указанное число сравнений соответствует числу разных межплощадочных пар в этом направлении.

Списки кандидатов чередуются с удалением повторов. Для авторской выборки использованы косинусы E5 и TF–IDF по названиям исходов и событий. Жёсткая версия применяет к тому же порядку отбор по совпадению кластера. Кластеры строятся сферическим k-means по текстовым представлениям всех контрактов без авторских меток. Это один алгоритм жёсткого разбиения. Исходные UMAP/HDBSCAN, набор статьи и её назначения кластеров здесь не воспроизводились.

| Данные, направление, k=20 | Запросов | Сравнений у каждого метода | Найдено при жёстком отборе | Найдено свободным объединением | Запросов без кандидатов в своём кластере |
|---|---:|---:|---:|---:|---:|
| 16 кластеров E5, Polymarket → Kalshi | 461 | 4 827 | 203/461 | 289/461 | 172 |
| 16 кластеров E5, Kalshi → Polymarket | 461 | 5 564 | 203/461 | 401/461 | 60 |
| 16 кластеров после отдельного центрирования площадок, Polymarket → Kalshi | 461 | 9 024 | 404/461 | 461/461 | 0 |
| 3 кластера TF–IDF, CPI, Polymarket → Kalshi | 7 | 0 | 0/77 | 0/77 | 7 |

Основной контраст использует seed 17. На авторских ссылках снятие жёсткой границы дало 86 дополнительных попаданий, или 18,66 п.п. Свободный E5 отдельно нашёл те же 289 ссылок; TF–IDF отдельно нашёл 286. Этим сравнением нельзя приписать прирост смешению двух каналов. В девяти сочетаниях числа кластеров (8, 16, 32) и seed (17, 29, 53) разность составила от 12 до 215 ссылок. При бюджете k=5 в основной конфигурации результат составил те же 203 и 289 при 1 365 сравнениях. Ранги относятся к 461 известной положительной ссылке из уже отобранных автором пар; остальные сочетания не исчерпывающе размечены.

**Дополнительная проверка после расчёта.** После обнаружения одноплощадочных кластеров из векторов каждой площадки вычли её средний вектор и заново нормировали строки только для кластеризации. При тех же 16 кластерах все запросы получили кандидатов, сохранилась разница в 57 известных ссылок (12,36 п.п.). Результат зависит от представления и границ кластеров. Вопрос о преимуществе перед любым жёстким тематическим разбиением остаётся открытым.

**Полностью перечисленный блок CPI.** На 385 межплощадочных сочетаниях независимый перебор допускаемых состояний в модели обычной публикации выделяет 77 связей. Архивных векторов E5 для этого блока нет. Первый канал использует все текстовые поля, второй только заголовок, оба на TF–IDF. В основной конфигурации все семь запросов остались без противоположной площадки в своём кластере, поэтому при равенстве фактического бюджета сравнение неинформативно. Если снять ограничение бюджета со свободного поиска, он находит 64/77 за 140 сравнений. Из девяти разбиений три дали ненулевой бюджет при k=20. Разности «свободный минус жёсткий» составили −5, +1 и +2 ссылки из 77. Для единственного полностью размеченного условного блока устойчивого выигрыша нет.

Из корня репозитория, Python 3.10+ и NumPy, при наличии восстановленных `redesign/retrieval/markets.json` и `reference_pairs.json`:

```sh
python3 experiments/semantic_audit/cluster_comparison/run.py
python3 -m unittest discover -s experiments/semantic_audit/cluster_comparison -v
```
