# Протокол до расчёта новых показателей, 17 ноября 2026

Это повторный анализ известных пилотов. Содержание E01/E02 и общие опубликованные числа были видны до фиксации. Все сравнения диагностические. Внешней регистрации, неизученного человеческого holdout и независимых аннотаторов в этом запуске нет.

1. **H1, известные ссылки.** На фиксированных 493 кандидатах противоположной площадки сравнить E5-small-v2 title и event+title, дополнительно BGE-small-en-v1.5. Основной показатель — попадание известной авторской ссылки same в top-20, равный вес семейства. Семейство — компонента двудольного графа заголовков событий Polymarket и Kalshi, соединённых одной из 493 исходных строк, включая неположительные. Направления усреднить внутри строки. Доверительный интервал — парный bootstrap целых компонент, 2000 выборок, seed 20261117. Практический порог +0.05; отдельно top-1, top-5 и положительные пары с token-Jaccard заголовков ≤0.25 (нижний регистр, буквенно-цифровые токены, без стемминга). Неразмеченные пары не являются отрицательными. Отдельно считать известные отрицательные ссылки, попавшие в top-20. Срез не измеряет полную recall сложных типизированных связей.
2. **H1, закрытый условный блок.** У всех 7 Polymarket-запросов ноябрьского Core CPI полный пул из 55 Kalshi-кандидатов. В обычной публикации один показатель и месяц считаются общим скаляром с шагом 0.1 п.п., разные месяцы свободны в модели. Релевантна любая пара, у которой хотя бы одно из четырёх состояний невозможно. Независимо от текста выявлять месяц у Kalshi для условного эталона из архивного event ID. Во всех четырёх представлениях одинаковый TF–IDF слов и косинус, tie-break по ID. Сравнить title; event+outcome; полные доступные правила; event+outcome+четыре повторения нормализованного ключа «показатель/период» (извлечь из текста, без ID). Основной показатель — Recall@20, вторичные @1,5 и precision@20. Этот блок содержит одно семейство. Сравнение полных правил относится к доступным текстам API. Отдельно рассчитать все совместные выплаты в сценарии задержки, допускающем разные выпуски; они остаются предположением эксперимента.
3. **H2, парные решения.** Повторно оценить сохранённые исходы direct/structured одной Qwen на 16 решаемых синтетических парах E01, восемь семейств логических шаблонов. Уровень покрытия состояний заранее 0.75, дополнительно 0.50 и 0.90; единый отбор по убыванию исходной confidence, внутри ничьей ожидаемые числа при случайном равномерном отборе. Основной риск — ошибочный запрет / все известные возможные состояния, получившие любой ответ. Дополнительно precision запретов, любая ошибка / отвеченные состояния, exact на общем множестве полностью решённых обеими ветвями, направление контраста по шаблонам. Практический выигрыш — снижение основного риска ≥0.05 без снижения precision. Разная схема ответа и наследование dev исключают подтверждение полного H2 заявки.
4. **H3, равный лимит дополнительных вызовов.** На тех же искусственных парах сравнить исходные structured→repeat, structured→critic, structured→critic+проверка и саму детерминированную проверку. Для равнобюджетного парного контраста critic+проверка vs critic и vs repeat разрешено по два LLM-вызова, одинаковый лимит выхода; фактическая стоимость раздельно. Основной риск и coverage как в H2. Считать отдельно correction, new error, wrong→unknown, correct→unknown и ошибки формата. Оценить перенос за пределы E01 отдельно на ранее сохранённых естественных шаблонах NLI: там нет дополнительной LLM.
5. **G1, проверка путями в графе.** В 839 ранее выделенных условных нижнепороговых парах Kalshi из разных шаблонов/серий проверить, отбирает ли требование логической поддержки по альтернативному пути более точные рёбра, чем confidence самой NLI, при одинаковом числе выбранных рёбер внутри каждой серии. Отдельно обрабатывать каждый исходный event+template; без эталона строить ориентированный граф импликаций литералов (включая контрапозиции). Проверяемую пару полностью убрать; поддержка есть, когда каждая заявленная невозможная комбинация следует из остальных рёбер. Основной эталон — истинность всех заявленных запретов для одного действительного скаляра, вычисленная по порогам из текстов независимо от графа. Порог практически значимого прироста precision +0.05, считать и ошибки, и покрытие; исключить пустые прогнозы. Не выбирать критерий по наблюдаемому эффекту. Отдельно сопоставить со слепым к модели правилом «большее значение порога влечёт меньшее» и с правилом только равной направленности операторов («оба могут быть истинны»). Количество уникальных серий, а не пар, задаёт границу переноса.
6. **G2, чувствительность к сценарию.** На всех 77 парах одного ноябрьского выпуска посчитать, сколько запретов обычной публикации теряются при допущении, что площадки вправе использовать разные месяцы. На каждом утраченном запрете предъявить конкретный числовой сценарий. Отдельно испытать контролируемые изменения математической модели: строгость порога Kalshi, непрерывная шкала вместо десятых и одновременная смена обоих условий. Это контролируемые альтернативы, не утверждения о фактическом урегулировании. Не ожидать независимых 77 наблюдений.

Не переносить результат с оценимого материала на неоценимый. Пустые знаменатели выводить как null. Для воспроизведения сохранить результаты на уровне ссылок/пар, hashes всех входных файлов и этого протокола, версии среды. Числа, дополнительные диагностические иллюстрации и исправления исполнения будут отделены от заранее заданных контрастов.
