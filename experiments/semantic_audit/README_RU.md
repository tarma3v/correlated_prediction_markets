## H1. Получает ли поиск больше связей?

Проверены 461 авторская положительная пара из 493 рассмотренных ссылок. У каждой стороны 493 рыночных кандидата с противоположной площадки. Внутри пары усреднены оба направления поиска, затем усреднены пары внутри семейства событий, затем 252 семейства с одинаковыми весами. Семейство объединяет исходные названия событий, соединённые по любой из 493 авторских ссылок. Интервалы получены 2000 парными выборками целых семейств с возвращением.

| Модель | Top-20, заголовок → с событием | Top-5 | Top-1 | Разность top-1, 95% интервал по семействам |
|---|---:|---:|---:|---:|
| E5-small-v2 | 100% → 100% | 99,00% → 100% | 85,81% → 98,73% | +12,92 п.п. [9,75; 16,40] |
| BGE-small-en-v1.5 | 100% → 100% | 99,05% → 100% | 86,66% → 98,40% | +11,74 п.п. [8,78; 14,75] |

В 371 положительной паре с Jaccard заголовков ≤0,25 top-1 у E5 вырос с 83,74% до 98,72%, top-20 остался 100%. Короткое название исхода само по себе уменьшает Jaccard. Разметка трудности по правилам договоров отсутствует. Контекст поднимает и известные отрицательные ссылки: у E5 в top-20 попали 52 из 54 их направлений по одному заголовку и все 54 с контекстом. Например, контракты о достижении Bitcoin $100k и об очерёдности достижения $50k/$100k оказались взаимными первыми кандидатами. Близость тематики помогает поиску и одновременно оставляет работу проверяющему компоненту. Пять авторских неопределённых пар исключены из сравнений по метке. Независимой полной разметки оставшихся комбинаций нет. [Построчные ранги](author_ranks.jsonl) · [Происхождение авторской выборки](../../redesign/datasets/author_audit_summary.json)

### Полностью перечисленный блок Core CPI

Каждый из семи Polymarket-контрактов одного ноябрьского события сопоставлен со всеми 55 архивными Kalshi-кандидатами по пяти месяцам. Для условного эталона приняты своевременная публикация в десятых долях п.п., обычное бинарное разрешение и независимые переменные разных месяцев. У всех 77 ноябрьских пар есть хотя бы одно невозможное совместное состояние, у 308 остальных в этой модели возможны все четыре. Месяц эталона Kalshi проверен по ID события, оператор и число — по полям strike исходного API. Polymarket-условие отдельно сверено с groupItemTitle. Все поисковые входы построены по тексту без рыночных ID, меток и цен.

| Представление одного TF–IDF | Связи в top-5, из 77 | Связи в top-20, из 77 | Precision@5 | Precision@20 |
|---|---:|---:|---:|---:|
| Заголовок | 9 | 77 | 25,7% | 55,0% |
| Событие + заголовок + исход, где доступно | 9 | 77 | 25,7% | 55,0% |
| Заголовки и доступные полные тексты API | 35 | 75 | 100% | 53,6% |
| Событие + исход + стандартизованный показатель и период | 35 | 77 | 100% | 55,0% |

Пространство признаков включает одинаковые правила токенизации и косинус для всех четырёх ветвей. Структурированный ключ повторён четырежды, как зафиксировано до запуска. В этом блоке единственный меняющийся компонент ключа — месяц выпуска. Для Polymarket ≤0,1% полный текст поместил ноябрьские Kalshi >0,7% и >0,9% на места 21 и 22. Полный блок измеряет условные связи в одном семействе, авторская выборка — попадание известных ссылок. Поиск сложных связей в новых семействах оставляет открытым основной вопрос H1. ## H2 и H3. Что происходит при одинаковом покрытии?

Повторный подсчёт использует 16 решаемых искусственных пар E01 с зафиксированными четырьмя состояниями, восемь логических шаблонов по два искусственных домена. Одна и та же Qwen3-4B-Instruct-2507 (MLX, 4 bit) уже обработала одинаковые исходные правила. Во всех ветвях сравниваются решения ровно на 75% состояний в ожидании. Отбор идёт по confidence, равные значения на границе включаются с одной и той же вероятностью для каждого случая этой ветви. Значения в таблице — отношения ожидаемых количеств. Риск ложного запрета равен числу ошибочно запрещённых состояний среди отвеченных эталонно возможных, precision — доле верных среди всех заявленных запретов.

| Ветвь | Риск ложного запрета | Precision запретов | Любая ошибка среди ответов |
|---|---:|---:|---:|
| Прямой ответ | 14,29% | 73,68% | 15,38% |
| Поля, цитаты, четыре состояния | 15,71% | 45,00% | 29,17% |
| Структурированный ответ + повторная оценка | 37,14% | 31,58% | 41,67% |
| Структурированный ответ + критик | 47,79% | 37,50% | 42,71% |
| Структурированный ответ + формальная проверка | 0% | 100% | 0% |
| Структурированный ответ + критик + формальная проверка | 0% | 100% | 0% |
| Только правила искусственного языка | 0% | 100% | 0% |

Целевой выигрыш H2 на 5 п.п. не достигнут. При покрытии 50% риски составили 14,29% и 19,57%; при 90% — 15,15% и 14,35%. На 15 парах, где обе ветви ответили на все состояния, точны 10 прямых и 5 структурированных ответов. Внутри семи шаблонов, где обе ветви достигают 75%, у structured одно поражение и шесть равенств. На восьмом шаблоне (строгая граница) риск у structured ниже, но она отвечает лишь на 50% состояний против 75% у direct. Общий результат меняется вместе с составом отобранных состояний. Разные интерфейсы отказа в старом E01 и маленький условный эталон ограничивают интерпретацию.

В ветвях H3 получен один и тот же исходный structured. Добавление критика исправило семь ошибок состояний и внесло 14 новых. Повторная оценка исправила две, внесла девять, перевела два ошибочных и два верных ответа в unknown. Формальная проверка после критика исправила 27 ошибок и не внесла новых. По 16 парам каждая из двухвызовных процедур имела 32 вызова с пределом 700 выходных токенов на вызов. У повторной оценки суммарно 53 230 входных и 9 292 выходных токена, 388,4 с. У критика 53 774 и 9 247, 390,0 с. Постпроверка той же ветви использовала ещё примерно 0,34 мс суммарно по старому журналу и ноль LLM-вызовов. Самостоятельный алгоритм правильно решает все эти задачи из-за ограниченной грамматики. На четырёх старых реальных парах полного эталона по-прежнему нет. ### Какие повреждения пропускает проверка цитаты?

Второй опыт H3 использует по одному исходному предложению Kalshi из 19 групп шаблонов. Для каждого подготовлены исходник, правильная переформулировка и восемь известных повреждений. Среди них неверный числовой порог, изменение выплаты, противоположный оператор и отрицание условия. Две серии использовались как development, шесть других — как перенос лексики и серий. Виды повреждений заданы разработчику.

| Проверка | Приняты правильные, перенос | Ошибочно приняты повреждения, перенос | Ошибочно приняты повреждения, все |
|---|---:|---:|---:|
| Цитата встречается дословно | 28/28 | 98/112 | 133/152 |
| Дополнительно сверены оператор, число и YES | 28/28 | 28/112 | 38/152 |
| Добавлены явные отсечки отрицания и исключения | 28/28 | 0/112 | 0/152 |

Заранее заданный порог снижения ошибок пройден на этих конструкциях. Контрпример вне десяти вариантов включён в тесты: после исходной фразы добавлено «A disputed release overrides this clause and pays one half.» Последняя проверка ошибочно принимает прежнюю заявку о выплате YES, хотя добавленная оговорка допускает выплату 0,5. Это конкретная граница словарной защиты. В таблице 190 предъявлений; этот дополнительный пример в ней не учитывается. ## G1. Может ли граф исправить неверную семантику?

Использованы архивные двунаправленные прогнозы DeBERTa-v3-base. Среди 1188 пар ровно 839 имеют ранее установленный общий пороговый шаблон, 19 групп из восьми серий. Из них 555 получили непустое отношение. Для каждой проверяемой пары удалены все её рёбра и контрапозиции. Предсказание сохраняется, если остальные рёбра делают невозможным каждое заявленное состояние. Контроль выбирает внутри той же серии ровно столько же предсказаний по confidence. Условный эталон вычисляется отдельно по операторам и порогам из исходных текстов. В этих данных отношения порядка проверяемы только при общем скаляре и обычном бинарном исходе.

| Серия | Выбрано | Корректно после поддержки графом | Корректно по confidence |
|---|---:|---:|---:|
| CPI | 4 | 0 | 0 |
| Core CPI | 6 | 0 | 0 |
| Core CPI YoY | 12 | 3 | 0 |
| CPI YoY | 5 | 0 | 0 |
| Годовой максимум CPI YoY | 3 | 0 | 0 |
| Палладий | 98 | 12 | 13 |
| Платина | 76 | 15 | 13 |
| Безработица U3 | 12 | 0 | 0 |
| **Всего** | **216** | **30** | **26** |

До фильтров полностью обоснованы 55/555 непустых заявок. Граф сохраняет 216/839 пар (25,7% всего); precision 13,89% против 12,04% у confidence. Средняя по восьми сериям разность +3,33 п.п., описательный bootstrap [−0,26; +9,70] п.п. Целевой выигрыш в 5 п.п. по наблюдаемой разности не достигнут; интервал допускает и выигрыш такого размера. Из 186 ошибочно поддержанных отношений 134 — эквивалентность, 33 — несовместимость и 19 — импликация неверного направления. Большая доля отобранных рёбер приходится на два металла, поэтому микро- и макрооценки различаются.

У октябрьских контрактов «CPI >0,4%» и «CPI >0,1%» DeBERTa дала среднюю contradiction 0,918. После удаления самой пары граф всё ещё запрещает состояние 11. При значении 1,4% оба условия выполнены. Правило совместимости односторонних нижних ограничений выявляет 325 ложных несовместимостей в исходных 839 парах; правило направления, использующее общий скаляр и порядок порогов, даёт правильное отношение на всех 839. Это проверка формально разрешимой подгруппы, отобранной по совпадающему шаблону. Остальные 349 входных пар остались вне оценки. [Все рёбра, условия и числовые свидетели](graph_edges.jsonl)

## G2. Как меняется тип связи при смене условий?

В обычном ноябрьском Core CPI блоке среди 77 пар 44 несовместимости без исчерпания, 26 импликаций Polymarket → Kalshi, четыре в обратную сторону, одна эквивалентность, одна комплементарная и одна исчерпывающая без несовместимости. Всего 79 запрещённых состояний. Подстановка ≥ вместо > в Kalshi меняет тип 9 пар; замена шкалы десятых на непрерывную — у одной пары; обе замены одновременно — у восьми. Например, ≥0,7% и >0,6% эквивалентны на десятых, а 0,65% опровергает эквивалентность на непрерывной шкале.

В тексте Polymarket предусмотрено использование предыдущего доступного месяца после дедлайна, в API Kalshi — продление при влияющем на данные федеральном shutdown. В условном сценарии независимых доступных значений за разные выпуски у каждой из 77 пар появляются все четыре состояния. Для каждого из 79 прежних запретов сохранена пара чисел, которая его нарушает. Это верхняя граница чувствительности к разрыву общей базовой величины. Приведение реального спорного разрешения к этому сценарию требует установления действующих документов обеих площадок и календаря публикаций. ## Воспроизведение

Из корня репозитория, Python 3.10+, стандартная библиотека. Если локально отсутствует производный reference_pairs.json авторского набора, его воспроизводит штатный подготовительный скрипт из закреплённого файла; в чистой копии для этого шага может требоваться сеть.

```sh
python3 scripts/fetch_reference_inputs.py
python3 experiments/semantic_audit/run.py
python3 -m unittest discover -s experiments/semantic_audit -v
```

Если reference_pairs.json уже есть, достаточно последних двух команд, полностью офлайн. Семь автоматических тестов проверяют среди прочего полный числовой перебор для CPI, соответствие графового алгоритма независимому перебору булевых миров, одинаковое покрытие сравнений и числа вызовов. SHA-256 входов, кода, протоколов и вычислительных результатов приведены в манифесте. [Манифест](manifest.json)
