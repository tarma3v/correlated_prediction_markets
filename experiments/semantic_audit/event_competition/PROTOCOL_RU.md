# Контекст события и выбор конкретного контракта

17 ноября 2026. Это вторичный эксперимент на авторских ссылках Polymarket–Kalshi. До расчёта ниже уже были известны глобальные ранги E5/BGE, общий прирост top-1 и потолок top-20. Отдельные результаты внутри целевого события ещё не были рассчитаны. Протокол локальный, без внешней регистрации.

**Вопрос.** Когда событие на противоположной площадке уже известно, помогает ли его заголовок выбрать нужный контракт из нескольких исходов? Практическая гипотеза — на неоднозначных запросах средний по семействам прирост top-1 E5-small-v2 от добавления заголовка события составляет не менее пяти процентных пунктов. Критерий описательный. Конкурирующее объяснение общего прироста — контекст позволяет найти само событие, а дополнительные слова почти ничего не дают для различения его исходов.

**Единица сравнения.** Для каждой исходной авторской положительной ссылки проверить оба направления. Группа кандидатов для направления строится по точному нормализованному заголовку события ссылочного контракта на целевой площадке. Допускаются все имеющиеся контракты целевого события среди 493 кандидатов, независимо от авторской метки. Основная подвыборка включает направления минимум с двумя такими кандидатами. Среднее берётся по направлениям одной ссылки, затем по ссылкам одной связной компоненты авторского графа событий и далее поровну по компонентам. Если осталась только одна сторона пары, она имеет вес всей пары. Сохраняются обе площадки и оба направления.

**Контрасты.** Для E5-small-v2 пересчитать по архивным матрицам точность top-1 известной ссылки для текста исхода и текста события с исходом. Привести аналогичную проверку для BGE-small-en-v1.5. В том же наборе направлений сравнить глобальный top-1 среди 493 и условный top-1 внутри одного события. Вычислить разность приростов в этих двух задачах. При равенстве максимальных оценок распределить вес равномерно по связанным кандидатам. У контроля, видящего только целевое событие, все его исходы неразличимы: ожидаемое попадание равно 1/n. Дополнительная диагностика — распределение размеров блоков, два направления отдельно и одиночные блоки. Не выбирать модель или подгруппу по результатам.

**Неопределённость.** Для каждой разности парный bootstrap целых компонент с 2000 повторов, seed 20261117; результат описывает чувствительность к эмпирическому составу. Условный выбор пула использует известную авторскую ссылку только для постановки диагностической задачи: его нельзя использовать в качестве доказательства автономного поиска. Источник был отобран авторами и содержит преимущественно положительные ссылки. Остальные контракты могут тоже оказаться допустимыми соответствиями. Показатель измеряет восстановление конкретного известного ID. Обобщение на независимые новые события и реальные договорные отношения требует отдельной разметки.
