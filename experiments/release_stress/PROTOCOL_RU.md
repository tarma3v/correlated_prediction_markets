# Устойчивость репликации к расхождению опубликованных значений

Проверяем разведочную гипотезу. Переход от одного общего значения core CPI к двум публикациям, расходящимся максимум на 0,1 п.п., способен изменить терминальную выплату воспроизводящего портфеля даже при правильном переводе корзин Polymarket в пороги Kalshi. В предыдущем сценарии допускались произвольные расхождения. Здесь величина расхождения ограничена до просмотра новых результатов.

Единица сравнения соответствует каждой из семи корзин ноября 2026. Из зафиксированной таблицы двух способов сопоставления читаем линейный портфель, оцениваем его при целых десятых процента и независимо вычисляем индикатор корзины. Для знакового портфеля сохраняем обе наихудшие ошибки и по одному свидетелю. Сравниваем совпадение значений, расхождение максимум на один и на два шага. Обе стороны наблюдают соответствующее им значение в области обычного бинарного расчёта. Вне крайних порогов все индикаторы постоянны. Область перебора включает по одному дополнительному шагу с каждой стороны после учёта максимального расхождения.

Основная величина есть доля из семи корзин, для которых портфель тождественен целевой выплате во всех допустимых состояниях. Разные точки сетки не считаются независимыми наблюдениями. Частота допустимых состояний в истории и вероятность особого порядка расчёта остаются неизвестными. Входные котировки не участвуют в определении исхода.
