# Насколько чувствительна репликация корзин CPI к разным публикациям

Семь ноябрьских корзин Polymarket сопоставлены с портфелями строгих порогов Kalshi. При общей публикации каждый правильно составленный портфель в точности воспроизводит корзину. Если значения у площадок могут разойтись хотя бы на 0,1 п.п., для каждой корзины существуют сценарии с недоплатой на единицу и с переплатой на единицу. В архивных данных такой случай не наблюдался. Это проверка допустимых состояний без назначения им вероятностей.

| Допустимое расхождение, п.п. | Полное совпадение корректного портфеля | Полное совпадение порога с таким же числом |
|---:|---:|---:|
| 0 | 7/7 | 0/7 |
| 0,1 | 0/7 | 0/7 |
| 0,2 | 0/7 | 0/7 |

Числитель показывает количество корзин, для которых тождество выполняется при **каждой** допустимой паре значений. Для корзины «ровно 0,3%» разность порогов «выше 0,2%» и «выше 0,3%» платит единицу только при значении Kalshi 0,3%. Если обе площадки берут 0,3%, корзина и портфель совпадают. Если Polymarket берёт 0,3%, а Kalshi 0,4%, расхождение выплат достигает единицы.

Из корня проекта запустите `python3 experiments/release_stress/run.py`. Скрипт читает сохранённую публичную таблицу построенных портфелей и независимо вычисляет выплату каждой стороны в целых десятых процента. Записаны минимальная и максимальная ошибки, значения обеих публикаций и выплаты при достижении этих границ. За пределами крайних порогов индикаторы постоянны, так что конечный перебор охватывает и оба хвоста.
