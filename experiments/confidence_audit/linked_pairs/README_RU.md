# Узнаёт ли отрыв от конкурентов семантически разные контракты?

В авторской разметке есть 461 положительная ссылка Polymarket–Kalshi, 27 отрицательных и 5 с неопределённым статусом. Для каждой ссылки сравнили два критерия. Первый принимает пару с достаточно высоким косинусом между текстами. Второй принимает пару, если косинус превосходит лучшую альтернативу для каждого из двух контрактов с достаточным отрывом. Тексты включают заголовок события и название исхода. Порог каждого критерия удерживает минимум 90% обучающих положительных ссылок, а проверяемое семейство целиком исключается из обучения.

| Модель | Критерий | Принято same из 461 | Принято different из 27 | Средняя доля принятых different по 19 семействам |
|---|---|---:|---:|---:|
| E5-small-v2 | Абсолютный косинус | 412 | 11 | 47,37% |
| E5-small-v2 | Отрыв от конкурента | 414 | 15 | 57,89% |
| BGE-small-en-v1.5 | Абсолютный косинус | 412 | 8 | 42,11% |
| BGE-small-en-v1.5 | Отрыв от конкурента | 414 | 15 | 63,16% |

**Результат.** Предсказание снижения ложного принятия на 10 п.п. не выполнилось. У E5 доля принятия отрицательных ссылок по семействам выросла на 10,53 п.п. (описательный 95% интервал от −15,79 до +31,58). У BGE рост составил 21,05 п.п. (от +5,26 до +42,11). Для положительных ссылок прирост принятия по 252 семействам составил 3,18 п.п. у E5 и 2,07 п.п. у BGE. Для правила, которое случайно принимает любую пару с вероятностью 0,9, ожидаемая доля принятия одинакова в обеих группах и равна 90%.

Например, правило с отрывом у обеих моделей приняло контракт на победу Half-Life 3 в номинации Game of the Year и контракт на выход Half-Life 3 в этом году. У E5 абсолютный косинус 0,903 оказался ниже порога 0,920, но отрыв 0,036 превысил порог 0,018. Пользователь такого результата получит тематически близкий контракт с другим условием выплаты.

**Границы.** Это повторная оценка фиксированного индекса из 493 авторских пар, прошедших исходный отбор. Граф из заголовков событий содержит 273 компоненты. Пороги не используют авторские ответы из проверяемой компоненты или отрицательные примеры. Эмбеддинги всех кандидатов доступны при поиске, а границы компонент построены по исходным ссылкам без учёта их класса. Из метрик исключены 5 строк unsure, их решения сохранены. Доля принятия отрицательных ссылок зависит от состава 19 наблюдавшихся семейств. Этот опыт не определяет вероятность ошибки для произвольного результата живого поиска. ## Воспроизведение

Из корня репозитория, Python 3.10+ и NumPy. Первая команда нужна при отсутствии производного авторского набора.

```sh
python3 scripts/fetch_reference_inputs.py
python3 experiments/confidence_audit/linked_pairs/run.py
python3 -m unittest discover -s experiments/confidence_audit/linked_pairs -v
```

При проверке все 986 отрывов пересчитываются с явным удалением самого контракта. Отдельно проверяются покрытие и максимальность каждого порога, изоляция проверяемого семейства, равенство максимальных косинусов и побайтовая воспроизводимость.
