# Уверенность поиска на авторских положительных и отрицательных ссылках

17 ноября 2026 года. До задания контраста уже были известны глобальные ранги ссылок, доля отрицательных ссылок в верхней части списка и результат сравнения внутрисобытийных рангов. Метрики двух правил допуска ниже ещё не смотрели. Это локальный ретроспективный план на использованном авторском наборе.

**Вопрос.** Помогает ли отрыв от ближайшего конкурента выявлять семантически разные контракты при сходном удержании ссылок с авторской меткой same? Если уникальный ближайший кандидат чаще соответствует тому же договору, то использование отрыва снизит число ошибочно принятых different по сравнению с абсолютным косинусом. Конкурирующее объяснение — уникальность тематики может дать большой отрыв даже двум различным контрактам.

**Методы.** У каждой исходной пары взять архивный косинус E5-small-v2 для представления event+title. Альтернативный показатель — меньший из двух отрывов этого косинуса от максимального косинуса со всеми другими кандидатами (одно направление на площадку). Обе шкалы считаются до использования авторской метки. Для каждой проверяемой компоненты графа событий использовать только положительные пары всех остальных компонент для порога. Взять наибольший наблюдавшийся положительный порог, при котором принято минимум 90% калибровочных положительных пар. При равенстве порогу принять пару. Все контракты входят в фиксированный поисковый индекс, исключение семейства относится к калибровке меток. Сохранить по каждой строке оба порога, размеры калибровки и решения. Эталон семантики ограничен метками внешнего автора; нерешённые метки исключить из знаменателей и перечислить.

**Предсказание и критерий.** Для E5 правило с отрывом понизит среднюю по семействам долю принятых different не менее чем на 10 процентных пунктов, при потере не более 2 п.п. средней по семействам доли принятых same. Привести обе сопряжённые разности (отрыв минус абсолютный косинус) с описательным bootstrap целых компонент, 2000 повторов, seed 20261117. Представить также прямые числители и знаменатели; для BGE-small-en-v1.5 повторить тот же контраст как проверку устойчивости. Контроль без признаков принимает каждую пару с вероятностью 0,9. Метрики вычисляются только на этих исходных ссылках. По ним нельзя оценить частоту ошибок среди всех пар в индексе или изначальной вселенной рынка. Порог 90% в калибровке не гарантирует удержание 90% в очередной семье; результаты не устанавливают внешний уровень ошибок или причинность.
