# Проверка риска при разных порогах уверенности

Сохранённые двунаправленные оценки DeBERTa пересчитаны на 839 однотипных парах Kalshi, отобранных прежним экспериментом. Для каждого договора из исходного текста извлечены порог и оператор. Два порога делят вещественную ось максимум на три открытых интервала и две граничные точки. Проверка представителя каждой области восстанавливает все возможные пары исходов для обычной бинарной выплаты по общему скаляру. Ошибкой ответа считается хотя бы один запрет, для которого найден численный контрпример.

| Порог | Высказался, пар из 839 | Покрытие | Ответов с контрпримером | Риск среди ответов |
|---|---:|---:|---:|---:|
| 0,50 | 794 | 94,6% | 725 | 91,3% |
| 0,80 | 555 | 66,2% | 500 | 90,1% |
| 0,90 | 346 | 41,2% | 302 | 87,3% |
| 0,95 | 177 | 21,1% | 157 | 88,7% |
| 0,99 | 17 | 2,0% | 17 | 100,0% |

При исходном пороге 0,80 получены 325 ошибочных исключений, 148 чрезмерных эквивалентностей и 27 ошибок направления вложения. Предыдущий показатель 325/839 считал лишь первый тип и включал молчание модели в знаменатель. Равновзвешенная средняя по восьми сериям среди ответов составляет 90,5%. Исключение любой одной серии даёт суммарный риск от 88,4 до 91,5%. Это анализ чувствительности по имеющимся данным.

При 0,99 остаются три серии с ненулевым покрытием. Например, в KXLCPIMAXYOY-27-P5.5 и KXLCPIMAXYOY-27-P4.5 модель запрещает совместное YES, хотя при общем наблюдаемом значении 6,5% выполнены оба условия. В обследованном корпусе повышение порога уверенности само по себе сохраняет логические ошибки даже после отказа почти по всем парам. Результат относится к выбранному преобразованию NLI и пороговым рынкам с оговорённой моделью выплат. Для произвольной редакции межплощадочного договора нужен отдельный эталон.

Из корня репозитория выполните `python3 experiments/confidence_audit/run.py`. Требуется стандартная библиотека. [Дизайн до расчёта](design.md), [сводка и результаты по сериям](results.json), [решения, запрещённые состояния и численные свидетели](decisions.csv).
