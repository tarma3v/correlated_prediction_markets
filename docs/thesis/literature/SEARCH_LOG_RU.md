# Журнал проверки источников

**Обзор охватывает сведения, доступные к 17.11.2026, UTC.** Цель поиска состоит в том, чтобы установить, какие методы и результаты уже опубликованы для сопоставления контрактов, определения выплат и оценки оракулов, и найти статью по приблизительной дате. Основной корпус включает четыре заданных идентификатора arXiv и один дополнительно идентифицированный препринт. Версии одного идентификатора учитывались как одна работа. Дополнительную работу выбирали по дате редакции и наличию метода, который проверяет ограничения совместных выплат по правилам контрактов. Это целевой обзор. Независимый двойной отбор работ не проводился.

## Проверка октябрьского каталога

Проверен полный месячный список раздела Quantitative Finance, включая работы, отнесённые к этому разделу дополнительно. В списке 365 записей. Для каждой извлечены номер arXiv и название, получено 365 названий без пропусков. В каждом названии без учёта регистра искали выражение `prediction[- ]markets?|polymarket|kalshi`. Найдено девять совпадений. Месяц в заголовке списка обозначает месяц включения в каталог. Даты подач и редакций проверялись по карточкам работ. [Октябрьский каталог arXiv, все 365 записей](https://arxiv.org/list/q-fin/2026-10?show=2000&skip=0).

Проверка воспроизводима по каталогу одного раздела и полю названия. Она пропускает работы с другими заголовками и категориями, а также новые редакции старых препринтов. Например, работу Fan и соавторов (cs.CY) нашёл отдельный веб-поиск, а v4 Capponi и соавторов обнаружена по истории исходного идентификатора. Для независимого поиска также запрошены arXiv Atom по дате первой подачи с 18 октября по 1 ноября и OpenAlex по дате публикации за тот же период. Запросы из рабочей среды завершились ошибкой разрешения доменных имён. Статистика 365/9 относится только к веб-каталогу arXiv. Поиск по первой подаче в этом окне сам по себе пропустил бы v1 Shi и Zhai от 16 октября.

Библиография содержит пять работ основного корпуса и четыре смежные работы. Для препринтов указаны год первой подачи на arXiv, URL версии и дата редакции. Для конференционных работ приведён DOI из выходных данных. Проверка формата BibTeX прошла для всех девяти записей. Дубликатов нет. Единственное предупреждение касается страниц Mahrous и Di Pietro. В опубликованной авторской записи BibTeX отсутствует диапазон страниц сборника, поэтому он оставлен незаполненным. При повторном использовании капитала и выкупе всей показанной глубины они оценили её в 3,5% в неделю относительно пикового капитала в открытых позициях. Оба показателя относятся к моделированию идеализированного исполнения. [v4, §5.1, табл. 5](https://arxiv.org/html/2610.23517v4).

## Проверка исходной таблицы оракула

Выгрузка Kota прочитана полностью и разобрана как CSV с учётом кавычек и встроенных переводов строки. Входному файлу соответствует Git blob `f48800a2e4e76d7926ed47a276bba63626108bf8`. Репозиторий указывает названия моделей и содержит результаты двух экспериментальных процедур. Пересчёт опубликованных голосов вынесен в [эксперимент по оракулу](../../../experiments/oracle_audit/README_RU.md). [Входной CSV](https://github.com/Tkota10/Senior-Thesis-Multi-LLM-Resolution/blob/f76754b5bcff1a1d7a50c2f1073a4b6d44bd985c/data/kalshibench_v2_evaluation_Filtered.csv) · [структура репозитория](https://github.com/Tkota10/Senior-Thesis-Multi-LLM-Resolution).

Код для проверки предполагает, что указанный CSV загружен в текущий каталог.

```python
import csv
from collections import Counter
from pathlib import Path

path = Path("kalshibench_v2_evaluation_Filtered.csv")
with path.open(encoding="utf-8", newline="") as source:
    rows = list(csv.DictReader(source))

groups = Counter(row["id"] for row in rows)
assert len(rows) == 1189 and len(groups) == 703
assert all(row["id"] == row["series_ticker"] for row in rows)
assert Counter(groups.values()) == {1: 217, 2: 486}
assert Counter(row["ground_truth"] for row in rows) == {"yes": 488, "no": 701}
for row in rows:
    if row["id"] == "KXNFLWINS-CLE":
        print(row["question"], row["close_time"])
```

Код нужен для проверки структуры и единиц наблюдения. Установить полноту поиска всех межплощадочных пар или перенести опубликованные оценки оракула на задачу пар по этому CSV невозможно. Реестр внешних цифр не содержит собственной оценки точности на реальных парах.
