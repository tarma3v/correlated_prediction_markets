# Журнал проверки источников

**Дата отсечения — 17.11.2026, UTC.** Задача целевого обзора — установить, какие методы и результаты уже опубликованы для сопоставления контрактов, определения выплат и оценки оракулов, и найти статью по приблизительной дате. Основной корпус включает четыре заданных идентификатора arXiv и один дополнительно идентифицированный препринт. Версии одного идентификатора учитывались как одна работа. Критериями отбора дополнения служили сочетание темы, даты и сходства с изложенной задачей. Полнота всей мировой литературы и независимый двойной отбор здесь не оценивались.

## Проверка исходной таблицы оракула

Выгрузка Kota прочитана полностью и разобрана как CSV с учётом кавычек и встроенных переводов строки. Git blob входного файла — `f48800a2e4e76d7926ed47a276bba63626108bf8`. Репозиторий называет версии моделей и содержит результаты прогонов A/B. Из существования файлов не следует, что опубликованные результаты пересчитаны здесь. [Входной CSV](https://github.com/Tkota10/Senior-Thesis-Multi-LLM-Resolution/blob/main/data/kalshibench_v2_evaluation_Filtered.csv) · [структура репозитория](https://github.com/Tkota10/Senior-Thesis-Multi-LLM-Resolution).

Код для проверки предполагает, что указанный CSV загружен в текущий каталог.

```python
import csv
from collections import Counter
from pathlib import Path

path = Path("kalshibench_v2_evaluation_Filtered.csv")
with path.open(encoding="utf-8", newline="") as source:
    rows = list(csv.DictReader(source))

groups = Counter(row["id"] for row in rows)
assert len(rows) == 1189 and len(groups) == 703
assert all(row["id"] == row["series_ticker"] for row in rows)
assert Counter(groups.values()) == {1: 217, 2: 486}
assert Counter(row["ground_truth"] for row in rows) == {"yes": 488, "no": 701}
for row in rows:
    if row["id"] == "KXNFLWINS-CLE":
        print(row["question"], row["close_time"])
```

Код нужен для проверки структуры и единиц наблюдения. Установить полноту поиска всех межплощадочных пар или перенести опубликованные оценки оракула на задачу пар по этому CSV невозможно. Реестр внешних цифр не содержит собственной оценки точности на реальных парах.
