# Внутренняя проверка рукописи

Рецензирование выполнено при подготовке черновика. Внешнего экспертного заключения и окончательного согласования автором пока нет.

| Проверенное утверждение | Что было сверено и как ограничен вывод |
|---|---|
| Частота ложных запретов NLI | Использованы два знаменателя. При пороге 0,80 покрытие равно 555/839, условный риск равен 500/555. Область ограничена обычной бинарной выплатой по общему скаляру. Подстановка 6,5% в два указанных предиката вручную даёт YES/YES. |
| Выигрыш от названия события | Семейное среднее top-1 и основная глубина 20 приведены вместе. Авторские ссылки не исчерпывают все положительные пары. В дополнительном опыте заранее известное целевое событие выделено как доступная только при оценке информация. |
| Проверка доказательства, графа и формата ответа | Семантическое решение отделено от валидного JSON. Ребро удаляется из графа перед получением альтернативного свидетельства. Успех на контролируемой порче не используется для оценки точности на незнакомых исключениях. |
| Экономический результат | Сторона сделки, стоимость комиссий и область выплаты сверены отдельно. Уравнение корзины «ровно 0,3%» проверено по обе стороны от границы. Полное совпадение по трём одинаковым месячным реализациям дополнено перебором возможных значений. Авторы не измеряли прибыль исполненных сделок. |
| Дневные регрессии | Все четыре модели сравниваются на общих строках. Предсказание последней ценой включено наравне с регрессией по собственным лагам. Для каждой панели приведено число прогнозов, в протоколе доступны границы временных блоков и результаты задержки источника. |
| Оракулы | Сверены отдельные знаменатели для опубликованных ответов, контрольной выборки, принятых решений и вручную сопоставленных биржевых исходов. При 292 верных решениях из 300 указаны 368 отказов из 668. Поздняя дата или пропущенное поле в архиве сами по себе не доказывают утечку в конкретном вызове. |
| Самостоятельность результата и версия статьи | Шкалу логических отношений и построение портфелей уже изучали другие авторы. Текст локализует вклад в измерении ложного запрета, индивидуальном числовом примере, тесте на один шаг публикации и размере эффекта при нескольких бюджетах просмотра. Дата 25 октября относится к v4 работы Shi и Zhai. |

Остающиеся ограничения по отдельным гипотезам и необходимый материал перечислены в [реестре](HYPOTHESES_RU.md). Из чистой копии кода с зафиксированными входами повторно получены 26 побайтово совпавших файлов семантических и ценовых результатов. Основная проверка оракула отдельно воспроизводит таблицы по контрольным суммам. Эти проверки выявляют ошибки сборки и переноса чисел. Для независимой научной оценки по-прежнему нужны человеческая разметка незнакомых семейств и рецензия руководителя.
