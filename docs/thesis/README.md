## Повторный расчёт

Команды запускаются из корня репозитория. Строки с загрузкой требуют доступа к публичным исходным архивам. Исходные версии зафиксированы в манифестах. Для числовой проверки, анализа снимков и основных расчётов оракула достаточно стандартной библиотеки Python 3.11. Для поиска нужны NumPy, для дневного прогноза также pandas. Создание графиков использует matplotlib. Условия изоляции и опциональных сетевых запусков указаны в протоколе оракула.

| Вопрос | Запуск или протокол | Что должно получиться |
|---|---|---|
| Когда NLI запрещает допустимый исход? | `python3 experiments/confidence_audit/run.py` | 500 ошибок на 555 ответов при пороге 0,80, 17 на 17 при 0,99 |
| Что дают контекст, граф и проверка условий? | Сначала `python3 scripts/fetch_reference_inputs.py`, затем `python3 experiments/semantic_audit/run.py` | [Поиск, сценарии CPI, оценка сохранённых ответов LLM, проверка рёбер и мутаций](../../experiments/semantic_audit/README_RU.md) |
| Где контекст меняет позицию ссылки? | `python3 experiments/semantic_audit/event_competition/run.py` | Для E5 +13,59 п.п. во всём индексе и +0,30 п.п. внутри заранее известного события на одной подвыборке |
| Помогает ли отрыв от второго кандидата? | `python3 experiments/confidence_audit/linked_pairs/run.py` | Фильтр E5 принял 15 из 27 отрицательных ссылок вместо 11 при пороге по сходству |

## Методика подготовки

Для проекта зафиксирована [ревизия научных инструментов K-Dense](https://github.com/K-Dense-AI/scientific-agent-skills/tree/ec59a29a03d5c40f73ab40878df04860bc00e876). Поиск публикаций, обзор литературы и проверка цитирования применены к версиям статей, датам и библиографии. При формулировке гипотез и проектировании экспериментов для каждого сравнения указаны единица анализа, исход и альтернативное объяснение. Статистический разбор учитывает зависимость пар внутри событий и дат внутри ценовых панелей. На этапе написания работы и внутреннего рецензирования основные числа сверены с таблицами, а условия применимости добавлены к выводам. Презентация использует те же таблицы, имеет отдельные заметки докладчика и резервные слайды по оракулам.
